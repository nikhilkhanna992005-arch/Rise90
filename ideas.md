# Rise90 — Design Direction

## Product character

**Rise90** is a private discipline operating system, not a gamified habit app. The visual language should feel like a calm, exacting control room: dense enough for useful information, but with generous negative space so the next action is always obvious.

## Chosen visual system

The dashboard will use a **midnight graphite** canvas with elevated blue-black surfaces, warm off-white typography, a restrained electric-lime progress accent, and violet/blue data accents. It will blend **Space Grotesk** for bold numerical hierarchy with **DM Sans** for efficient body text. Cards will use 16–20px radii, thin low-contrast borders, soft shadow depth, and a faint radial grid texture.

## Layout principles

The primary desktop composition will be a fixed left navigation rail, a spacious main workspace, and a contextual right rail for live day context. The mobile layout will collapse into a compact top header plus bottom navigation. Today’s actions will remain above the fold, while analysis and history remain one scroll away.

## Motion and interaction

Completion controls will give brief press feedback, check-state transitions, and limited success emphasis. Chart hover and calendar inspection will use concise tooltips/panels. Milestone celebration will be small and non-blocking. All non-essential motion will honour reduced-motion preferences.

## Data behavior

The UI will present only real persisted user data. A clear, deliberate empty state starts a challenge; no fabricated reviews, testimonials, or always-on fake activity will be used. Historical days may be opened and edited, while future days remain locked.
